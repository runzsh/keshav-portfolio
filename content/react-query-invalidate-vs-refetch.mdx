React Query simplifies data fetching and caching in React apps. Choosing between `invalidateQueries` and `refetchQueries` is critical for performance and UX. Here’s a breakdown.

---

## Understanding `invalidateQueries`

### What It Does

Marks a query as stale. The next time it’s accessed, it refetches. It does **not** refetch immediately.

### How to Use It

```ts
import { useQueryClient } from "@tanstack/react-query";
const queryClient = useQueryClient();

// Invalidate a specific query
queryClient.invalidateQueries({ queryKey: ["user", userId] });

// Invalidate all queries
queryClient.invalidateQueries();
```

### When to Use It

- ✅ Data may be outdated but not immediately needed.
- ✅ After a mutation that updates data without needing instant UI refresh.
- ✅ Batch invalidations to prevent redundant calls.

---

## Understanding `refetchQueries`

### What It Does

Immediately refetches matching queries, even if they aren’t stale.

### How to Use It

```ts
queryClient.refetchQueries({ queryKey: ["user", userId] });
```

### When to Use It

- ✅ Fresh data is needed immediately after a mutation.
- ✅ Component is unmounted, but cache must update.
- ✅ Force updates for real-time sync.

---

## Key Differences

| Feature           | `invalidateQueries`  | `refetchQueries`              |
| ----------------- | -------------------- | ----------------------------- |
| Effect            | Marks query as stale | Forces immediate refetch      |
| When it refetches | On next use          | Immediately                   |
| Performance       | More optimized       | May cause redundant API calls |

---

## Choosing the Right One for Your Use Case

### ✅ Use `invalidateQueries` when:

- You want lazy refetching.
- You’re updating multiple queries at once.
- You aim to optimize API usage.

### ✅ Use `refetchQueries` when:

- Immediate fresh data is needed post-mutation.
- The consuming component isn’t mounted.
- You need instant cache sync for real-time data.

---

## Final Thoughts

Use `invalidateQueries` for performance-sensitive updates. Use `refetchQueries` for instant synchronization. Choosing the right tool ensures your React Query logic remains efficient and scalable.
